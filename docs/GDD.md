# 🎮 ChessWar Game Design Document (GDD)

## 1. 사전 설정 (Pre-game)
### 체스판 지정
- 명령어로 기준점 설정. 플레이어 위치가 왼쪽 아래(0,0) 기준.
- 플레이어 시선 방향이 Forward, 우측이 Right로 확장.

### 팀 참가 및 탈퇴 UX
- **참가**: 팀 색상 양털을 손에 들고 우클릭. (마인크래프트 기본 블록 설치 이벤트 유지)
- **탈퇴**: 참가한 팀의 양털 블록을 파괴(Break) 시 탈퇴 처리.

## 2. 게임 단계 (Phases)
### Phase 1: 기물 선택 (Piece Selection)
- **킹 필수 배정**: 각 팀에 '킹'은 반드시 존재해야 함. 아무도 선택하지 않을 경우 시스템이 참가자 중 한 명을 무작위로 강제 배정.
- **텔레포트**: 참가자들은 각 팀 막사로 이동. (백: D-E 사이 Rank 7, 흑: D-E 사이 Rank 2)
- 5분 제한 (모두 선택 시 10초 단축), 미선택 시 나머지 기물 랜덤 배정.
- **제한**: 오직 이 단계에서만 기물 선택 가능.

### Phase 2: 순서 조율 (Turn Order)
- **상자 생성**: 단계 시작 시 막사 내 Double Chest 생성. 상자 안 '순서 아이템'으로 순서 결정.
- **보안**: [준비 완료] 버튼(상자 맨 하단 중앙)은 현재 단계에서만, 그리고 해당 진영 소속 플레이어만 상호작용 가능.
- **타임아웃(3분)**: 미준비 시 시스템이 순서를 무작위(Random)로 섞고 강제 시작 (모두 준비 시 10초 단축).

### Phase 3: 전투 (Battle)
- **전개**: 시작 시 순서 조율 상자를 제거하고, 참가자들을 메인 체스판의 선택한 기물 위치로 텔레포트.
- 라운드 로빈 방식 (백1 -> 흑1 -> 백2 -> 흑2 ...).
- **턴**: 골드 획득, [이동 or 공격] 1회 가능. (매 턴 소량 회복 제거)
- **시각적 가이드**: 자신의 턴에 무기를 들면 이동 가능한 빈 칸은 '초록색 유리(LIME)', 공격 가능한 적군은 '빨간색 유리(RED)'로 표시.
- **타이머 (팀 공유)**: 각 팀은 **기본 공유 시간 10분**을 가지며, 기본 시간이 소진되면 턴마다 **30초 초읽기** 적용.

## 3. 기물 특수 능력 및 초기 스탯 (Abilities & Stats)
### 스탯 산출 공식: [1점당 체력 20 / 공격력 5]
| 기물 (가치) | 체력 (HP) | 공격력 (ATK) | 특징 및 특수 능력                                  |
| :--- | :--- | :--- |:--------------------------------------------|
| **폰 (1점)** | 60 | 15 | 기본 보병. 상대 진영 끝 도달 시 승급.                     |
| **나이트 (5점)** | 100 | 25 | **비선제 공격**: 공격 대상의 공격 범위 밖에서 타격 시 추가 피해 부여. |
| **비숍 (5점)** | 100 | 25 | 대각선 이동. 아군 타격 시 회복 (자힐 가능).                 |
| **룩 (7점)** | 160 | 20 | **황금 체력** 부여. 자신의 턴이 되면 수리(리필). |
| **퀸 (9점)** | 140 | 35 | 전방위 이동. 하이엔드 딜러 (룩/비숍 능력 하위호환).             |
| **킹 (10점)** | 260 | 10 | **최고 존엄 체력**. 최소 호신권(ATK 10) 보유.            |

### 킹의 특권 (Commander)
- **병력 강화**: 골드를 소모하여 특정 직업군(폰, 나이트 등) 전체를 강화. (플레이어/NPC 모두 적용)
- **지휘권**: 플레이어가 선택하지 않은 아군 NPC 기물들을 제어. 
  - **선택**: 킹의 턴에 아군 NPC를 [좌클릭]하여 지휘 대상으로 지정 (이동 가이드 실시간 갱신).
  - **명령**: 대상 지정 후 빈 칸 [우클릭] 시 이동, 적군 [좌클릭] 시 대상 NPC가 공격 수행.
  - **해제/변경**: 다른 아군 클릭 시 즉시 변경, 동일 아군 다시 클릭 시 해제.

## 4. 경제 및 상점 (Economy & Shop)
- **골드 수급**: 턴당 월급(50G), 처치 보상(200G), 세금(킹), 탈취(Steal).
- **상점 (F 키)**: 전투 단계에서만 이용 가능하며, 킹 전용 강화와 개인 강화로 나뉨.
- **개인 강화**:
  - **체력 강화**: 최대 체력 +10 HP (200G)
  - **공격력 강화**: 공격력 +2 ATK (250G)
- **전술 아이템**:
  - **도약 (300G)**: 이번 턴에 아군 기물 하나를 뛰어넘어 이동 가능. (룩, 비숍, 퀸 기물은 전투 시작 시 1개 기본 지급)
  - **기타**: 포션, 강령술, 휘두르기, 포박, 침묵 등 (추가 예정).
- **기물 클래스 강화 (킹 전용)**: 킹이 골드를 소모하여 특정 기물군 전체의 스탯(체력 +20, 공격력 +5)을 영구 강화.

## 5. 승리 및 종료 (Ending & Cleanup)
### 승리 조건
- 상대 킹 처치(체크메이트) 시 승리 및 종료 단계 진입.

### 전투 종료 리포트 (UX)
1. **홀로그램 통계**: 체스판 중앙 공중에 딜량, 힐량, 탱킹량, 골드 수급/사용, 킬/데스/어시스트 통계를 홀로그램(허공 텍스트)으로 표시.
2. **기록 책자**: 명령어 입력 시 세부 데이터가 기록된 [전투 기록 일지(Written Book)] 지급.

### 정리 (Cleanup)
- 종료 단계가 끝나고 대기 단계(WAITING)로 돌아갈 때 필드의 모든 엔티티, 블록 가이드, 홀로그램 등을 일괄 청소.
